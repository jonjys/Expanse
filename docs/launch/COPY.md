## Eventuell HN-presentation — endast om den passar Show HN-reglerna

Title: Show HN: Expanse, a galaxy map for discovering software

I built Expanse as an experiment in visual discovery: a canvas galaxy tied to a catalog you can also search by the problem you have.

You can try it without signing up. The catalog is early; the fuller demo is clearly labeled and uses fictional products.

Makers can submit a free profile. Search rank and the earned Spotlight cannot be bought. Product discovery stats separate map exploration from search and shared links.

I'm interested in whether the spatial view helps you discover anything you'd miss in a list. Happy to discuss the implementation and tradeoffs.
